Evaluation Guidance

Normal Requests: Alphanumeric search terms and legitimate file requests pass cleanly through the rule matrix without triggering any signature, returning HTTP 200 OK.

Malicious Requests: Requests containing recognized SQL syntax (e.g. boolean tautologies, UNION), HTML script injection or event handlers, or parent directory climbing tokens (../) trigger the rule engine and are terminated with an HTTP 403 Forbidden blocked page.

Audit Verification: Every test generates an entry in the SQLite audit log accessible on the Security Logs tab.
